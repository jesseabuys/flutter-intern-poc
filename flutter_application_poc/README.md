A new Flutter project.

An app with a login screen, contact us, main menu and a profile.

Login screen pauses for 2 seconds to mimic a login and takes you to our main menu page.

From main menu we can go to the other 3 screens of the app, contact us, profile and you can return to the login screen by logging out.

Contact us has a section for our company's details and a form for filling out a message. If any of the fields are empty then the message will not be able to send. If the email is not valid then there will also be an error.

Profile page has fields containing the user's information and changes made in this page will be stored after app restart.
